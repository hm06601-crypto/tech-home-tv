# Tech Home TV

Tech Home TV is a cross-platform player for **your own** IPTV playlists
(M3U / M3U8, Xtream Codes, Stalker portals). It does **not** include any
channels, playlists or content: each user adds their own source.

- Platforms: Windows (installer) and Android (APK)
- Default language: Arabic (right-to-left), English available in Settings
- Contact: WhatsApp / phone +964 774 464 4492 · https://techhome.ct.ws

## Building

Builds run on GitHub Actions (Actions tab):

| Workflow | Output |
|---|---|
| Tech Home TV - Windows (EXE) | `TechHomeTV-windows` artifact: `*-setup.exe` |
| Tech Home TV - Android (APK) | `TechHomeTV-android` artifact: `TechHomeTV-<version>.apk` |

Step-by-step instructions (Arabic): [TECHHOME_SETUP_AR.md](TECHHOME_SETUP_AR.md)
